# Задачи

Страница задач на React + TypeScript: фильтр по приоритету и создание задачи
через модалку. Без бэкенда — данные живут в браузере.

## Что умеет

- Список задач с чекбоксом выполнения и удалением
- Фильтр по приоритету: Все / Низкий / Средний / Высокий, с количеством
  задач в каждой категории
- Создание задачи через модалку: название, описание, приоритет, валидация
- Моковые данные при первом запуске
- Сохранение изменений в `localStorage`
- Сброс списка к мокам

## Запуск

```bash
npm install
npm start        # http://localhost:3000
npm test         # тесты в watch-режиме
npm run build    # production-сборка в build/
```
